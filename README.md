# 唐山港能源综合管控平台

用于评审业务结构、页面表达和交互流程的前端工程。采用Vite及原生JavaScript，无运行时外部CDN依赖。

后续页面迭代遵循 `planning/界面内容原则.md`：界面面向最终使用者，只呈现业务任务、结果和必要规则；工程说明留在交接文档。

## 本地运行

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。登录账号为 `admin`，密码为 `123456`。日期默认2026年10月，右上角可切换岗位视角。页面中的设备、计量和运行记录为集中组织的样本，不代表客户生产数据。

```powershell
npm test
npm run build
npm run preview
```

## 文件分工

- `src/data.js`：组织、设备、表计、维护、因子、用户、菜单及权限的初始数据。
- `src/domain.js`：周期统计、分组、碳排放、线损、完好率、CSV格式等纯业务逻辑。
- `src/carbon-model.js`：因子生效区间、引用规则、逐日核算与不可变批次快照。
- `src/enhancements.js`：因子管理、多能源报表、组织角色菜单配置。
- `src/model-upgrade.js`：兼容旧浏览器数据，旧手工因子迁移为草稿。
- `src/store.js`：本地持久化与操作记录；生产接入时替换为服务接口。
- `src/ui.js`：表格、图表、指标、状态和图标组件。
- `src/main.js`：18个页面及关联交互。
- `planning/pages.json`：稳定页面ID及实现状态，是Excel更新输入。
- `outputs/energy-planning/能源平台页面规划与进展.xlsx`：持续更新的页面台账与讨论记录。
- `planning/本轮实现与后续衔接.md`：本轮边界、依据与后续安排。

## 数据与交互

统计采用一套设备用电数据，组织汇总、碳核算、线损出线与报表可互相核对。样本数据截至2026年10月31日；2026年年报为截至10月底的累计结果。表底按累计电量与倍率生成，和周期用量区分。

维护、因子、用户与角色配置保存在浏览器的 `tangshan-energy-v1` localStorage项中。需要恢复初始状态时仅删除该项并刷新。该操作会清除本机在页面中的修改，执行前自行保留需要的内容。

集团上报重试只加入本地待发送队列，不实际调用外部接口。登录使用浏览器会话与前端账号校验，不提供服务端身份验证或访问安全保障。组织、角色数据范围、菜单启停与排序已支持配置；新增用户仍不产生真实登录身份。

碳因子来源为生态环境部与国家统计局2023年电力二氧化碳排放因子公告，页面保留来源链接；当前包含重点设备、公共用电、柴油和天然气活动量；油气因子缺失时明确显示待核算，不用部分电力排放冒充全港总量。因子库状态与核算引用分离，逐日选版本，保存批次后固定活动量、规则、因子及结果。具体规则、初始化假设、逐项需求差距和后端契约见 `planning/需求复核与因子核算设计.md`。

## 台账更新

先读取Excel内的用户意见和决定，再修改页面和 `planning/pages.json`。`tools/build-ledger.mjs`导入最新工作簿并按页面ID做增量修改，保留样式、公式、历史讨论和L/M列。`planning/ledger-baseline.json`用于识别其他列的人工修改；有冲突则保留人工值并报告，不能盲目覆盖。运行时使用本机bundled artifact-tool，不纳入应用依赖。

## 验证

`npm test` 检查跨日月汇总、分组一致性、碳单位换算、线损零分母/缺数、表底与倍率、维护完好率、日期及CSV注入防护。

`tools/browser-check.mjs` 使用本机预装Playwright和Chromium检查18个路由、5台门机筛选、资产保存、维护流程、因子版本、上报队列、角色范围、CSV下载，以及1440、1366和390像素布局。脚本使用隔离浏览器上下文，不会更改用户浏览器数据。该脚本中的本机运行时路径需在其他机器调整。

`npm run build` 输出静态文件到dist。通过 GitHub Actions 发布到 GitHub Pages，访问地址为 https://wadecheung-sys.github.io/energy-2611/ 。推送main会自动测试、构建和发布。客户原始截图和提取正文保留本地，不提交到公开仓库。

页面台账最新版本为 outputs/energy-planning/能源平台页面规划与进展-v0.3.xlsx；此前版本保留。本轮核查和交接记录见 planning/需求复核与因子核算设计.md。
